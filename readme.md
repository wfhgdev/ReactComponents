# ⚛️ React Clone Cards - Testimonios de FreeCodeCamp

Este proyecto es un taller práctico desarrollado para el aprendizaje de los conceptos iniciales de **React**, enfocado principalmente en la creación y reutilización de **Componentes** y el paso de datos a través de **Props**.

El objetivo principal es replicar las tarjetas de testimonios de la página de inicio de FreeCodeCamp, manteniendo una estructura modular, limpia y escalable.

---

## 🚀 Demo en Vivo

* **Sitio desplegado en Vercel:** [https://react-components-green-iota.vercel.app/](https://react-components-green-iota.vercel.app/)

---

## 🛠️ Tecnologías Utilizadas

* **React** (Biblioteca principal de UI)
* **JavaScript (ES6+)**
* **HTML5 & CSS3** (Estilos y maquetación)
* **Vite**
* **Vercel** (Despliegue e integración continua)

---

## 📋 Requisitos e Implementación del Taller

- [x] Estructuración del componente principal de tarjeta (`Testimonio`).
- [x] Implementación de **Props** para dinamizar nombres, países, cargos, empresas, imágenes y texto.
- [x] Completado de los testimonios faltantes asignados como ejercicio práctico.
- [x] Aplicación de buenas prácticas de código (**Clean Code**).
- [x] Despliegue continuo configurado en **Vercel**.

## ⚙️ Instalación y Ejecución Local

Sigue estos pasos para ejecutar el proyecto en tu entorno local:

### 1. Clonar el repositorio
```bash
git clone https://github.com/wfhgdev/ReactComponents.git
cd tu-repositorio
```
### 2. Instalar dependencias
```Bash
npm install
```
### 3. Levantar el servidor de desarrollo

```Bash
npm run dev
```

### 4. Ver página en el navegador

Abre tu navegador en http://localhost:5173 (Vite) para ver la página Web corriendo.
